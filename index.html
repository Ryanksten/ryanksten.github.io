03 · How I work

Three rules that survive contact with production

  1. 01 Systems of record first

    If Salesforce, the ledger, or the clinical system does not move, the model does not matter. Integrate before you prompt. Chat windows that never write back are theatre.

  2. 02 Readiness before model worship

    Most failed AI projects skipped the unglamorous scan: data access, owners, failure modes, and what “done” looks like in the existing stack. Architecture and sequencing beat a clever demo.

  3. 03 Pilot to habit

    A workflow is finished when it is monitored, owned, and boring — not when the demo lands. Build the path, name the operator, leave the docs.
